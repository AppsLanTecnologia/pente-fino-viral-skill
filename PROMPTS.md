# Prompts da skill pente-fino-viral

Copie, troque o que está entre [colchetes] e cole no Claude Code. Quanto mais você contar sobre o **seu** vídeo, mais o roteiro sai com a sua cara.

---

## 1. Instalar (uma vez só)

```
Instale a skill pente-fino-viral para mim:
1. Rode: git clone https://github.com/AppsLanTecnologia/pente-fino-viral-skill ~/.claude/skills/pente-fino-viral
2. Verifique se ffmpeg, yt-dlp e whisper estão instalados. Instale o que faltar, do jeito certo para o meu sistema, e me diga o que instalou.
3. Rode o script com --help para confirmar que funciona.
Não peça minha senha no chat: se precisar de permissão de administrador, me diga o comando que eu mesmo rodo.
```

Depois de instalar, **feche e abra o Claude Code** para ele enxergar a skill nova.

---

## 2. Fazer o pente fino e modelar para o seu vídeo (o principal)

```
Use a skill pente-fino-viral.

Vídeo de referência: [cole aqui o link do Reel, TikTok ou Short]

Sobre o MEU vídeo:
- Assunto: [sobre o que vai ser o seu vídeo]
- Quem eu sou: [ex.: nutricionista, dev de apps, loja de roupas, personal trainer]
- Público: [para quem é o vídeo]
- Formato: [rosto na câmera / só narração / tela gravada / animação]
- Objetivo: [ganhar seguidores / gerar comentários / vender / levar para o link]
- Duração: [ex.: 30 a 45 segundos]
- Chamada final: [ex.: comenta PALAVRA que eu te mando X / me segue / link na bio]
- Números reais que posso usar: [ex.: 3 anos de experiência, 200 clientes; ou "nenhum"]

Faça o pente fino completo do vídeo de referência e me entregue o roteiro modelado momento a momento: o que falar, o que aparece na tela, como gravar e como editar. Copie a estrutura e o ritmo, nunca as frases do original. Não invente números sobre mim.
```

---

## 3. Depois da análise (ajustes)

**Mais ganchos**
```
Me dá mais 3 ganchos de famílias diferentes para o meu roteiro, cada um com o texto da tela e o que aparece no primeiro segundo. Marque o mais forte e diga por quê.
```

**Mudar a duração**
```
Reescreva o roteiro modelado para [15 / 30 / 60] segundos, mantendo o gancho e a chamada final.
```

**Lista de gravação**
```
Transforme o roteiro numa lista de takes na ordem de gravação: enquadramento, onde olhar, o que dizer e quantas vezes repetir cada um. Inclua as imagens de apoio que eu preciso gravar.
```

**Legenda do post**
```
Escreva a legenda do post: primeira linha com gancho, 2 ou 3 linhas de conteúdo, a chamada final e 5 hashtags do meu nicho.
```

**Comparar dois vídeos**
```
Faça o pente fino também deste vídeo: [outro link]. Compare com o anterior e me diga o que os dois têm em comum, porque isso é o padrão que funciona no meu nicho.
```

---

## 4. Se algo der errado

**O download falhou** (post privado ou Instagram pedindo login): baixe o vídeo pelo celular ou computador e mande:
```
O download falhou. Baixei o vídeo, está em [caminho do arquivo .mp4]. Faça o pente fino a partir dele.
```

**Faltam as visualizações** (o Instagram costuma esconder esse número):
```
O vídeo tem [X] visualizações e o perfil tem [Y] seguidores. Use esses números na análise das métricas.
```

**A análise ficou genérica:**
```
Seja mais específico: para cada técnica, me diga o segundo exato em que ela aparece e mostre a evidência (quadro, fala ou número do resumo).
```
